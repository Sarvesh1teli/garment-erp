Billing SMS Gateway

Service online

Connect your desktop billing app to your Android SMS phone, even on different networks.

Set up a customer installation

  1. In the desktop app, open Settings → SMS Gateway and select Register & Pair.
  2. Your desktop receives a unique GRM-… code immediately. Generate a new one-time pairing code for each phone.
  3. Open Teli Garment Gateway on Android. Enter this server address, your desktop code, app code GARMENTERP and the pairing code.
  4. Start the Android sender and enable automatic bill SMS in the desktop settings.
Each customer installation has its own credentials and queue. Manage registration and pairing from the desktop app. Check service health
